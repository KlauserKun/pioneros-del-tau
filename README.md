# Pioneros del Tau — Hasta pronto, familia

Página de despedida temporal del clan **Pioneros del Tau** (Warframe, alianza Dinastía Tau).

- Emblema azul del clan al centro, con anillos HUD cibernéticos.
- Fondo cyberpunk y música de Cyberpunk Edgerunners.
- Mensajes para la familia, los gerentes y Benja.

Hecho con HTML, CSS y Three.js. Publicado con GitHub Pages.
